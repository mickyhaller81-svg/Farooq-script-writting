## Notes
- `check_speech.py` is a local version of the checker the rules mention (§7). It covers only the mechanical rules. Hook, flow, originality and repetition still need a full read.
- 04 includes one gentle, general line pointing to a crisis line or a trusted person. It gives no numbers and no medical advice.
- 05 is a parable. The main character is fictional and the narrator says so.
- Every story character has a different name in each episode, so no name comes back in a later speech. Walter is used only in 05.
